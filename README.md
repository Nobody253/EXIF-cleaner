# EXIF cleaner

**EXIF cleaner** - это кроссплатформенное веб-приложение (PWA) для просмотра и удаления метаданных (EXIF) из фотографий.

## Описание проекта

Приложение позволяет загружать изображения, просматривать основные EXIF данные и скачивать обработанные локально через HTML5 Canvas копии файлов без всех EXIF-тегов.

## Поддерживаемые форматы изображений
* JPG, PNG, WebP - результат в исходном формате.
* HEIC / HEIF - результат конвертирован в JPG.

## Технический стек

* **HTML5 / CSS3**
* **JavaScript (ES6+)**
* **Service Worker API** - кэширование ресурсов для офлайн-доступа.
* **Библиотеки:**
    * [ExifReader](https://github.com/mattiasw/ExifReader) - парсинг метаданных.
    * [heic2any](https://github.com/alexcorvi/heic2any) - конвертация HEIC в JPEG.
    * [JSZip](https://github.com/Stuk/jszip) - генерация ZIP-архивов.

## Инструкция по использованию

1.  Перетащите изображения в зону загрузки или нажмите на неё для выбора файлов.
2.  Приложение покажет найденные основные EXIF-теги (если они есть).
3.  Нажмите кнопку **"Скачать без метаданных"** или **"Скачать все архивом (ZIP)"**.
4.  На устройство сохранится копия файла с пометкой `_cleaned` или архив с копиями всех изображений соответственно.

### Установка приложения (PWA)

* **Android (Chrome):** Нажмите на меню (три точки) -> "Добавить на главный экран".
* **iOS (Safari):** Нажмите кнопку "Поделиться" -> "На экран «Домой»".
* **Desktop (Chrome/Edge/Firefox):** Нажмите иконку установки в правой части адресной строки.
